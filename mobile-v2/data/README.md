# Cenník zariadení

Tento priečinok je centrálny zdroj zariadení pre Spektra Ponuky.

Súbor `device-catalog.json` obsahuje:
- kategóriu,
- značku,
- model,
- výkon / variant,
- dodávateľa,
- nákupnú cenu bez DPH,
- predajnú cenu bez DPH,
- rabat,
- cieľovú maržu,
- aktiváciu položky.

Ceny sú zatiaľ prázdne zámerne. Budú sa dopĺňať z aktuálnych dodávateľských cenníkov, aby sa nevymýšľali ani nezostali zastarané.

Odporúčaný ďalší krok:
1. Panasonic / KLIMAVEX
2. Vaillant / Ptáček
3. Midea
4. Hyundai
5. Mitsubishi
6. Klimatizácie podľa značiek
