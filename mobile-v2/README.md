# Spektra Ponuky – Mobile / Tablet v2

Mobilne optimalizovaná verzia aplikácie na tvorbu cenových ponúk pre Spektra Install.

## Funkcie
- responzívne rozloženie pre mobil, tablet a desktop,
- spodná mobilná navigácia,
- tvorba ponuky zo šablóny alebo textového popisu,
- šablóny: tepelné čerpadlo, klimatizácia, ZTI, servis,
- položky, množstvo, MJ, predajná cena a interný náklad,
- automatický výpočet DPH, zľavy, zisku a marže,
- ukladanie ponúk do localStorage,
- tlač / uloženie do PDF,
- export CSV a JSON zálohy.

## Spustenie
Otvorte `index.html` v Chrome, Edge alebo Safari.

## Stav
MVP. Nahratie PDF/XLSX je pripravené v UI, ale súbory sa ešte automaticky neanalyzujú. Ďalší krok: PWA, databáza, import cenníkov a napojenie na POHODA.
